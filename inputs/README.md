# inputs/

Drop raw material here for me to look at. Anything goes:

- **Sample data** — CSV, Excel, JSON exports (e.g. a product/perfume list, price sheet, inventory)
- **Images** — logos, brand assets, screenshots, UI sketches, reference designs
- **Docs** — API documentation, PDFs, requirement notes, spreadsheets
- **Links** — paste URLs into `INTAKE.md` section 5/7, or drop a `links.md` here

## Tips
- If you add a file, mention it in `INTAKE.md` (section 4 for data, section 7 for design) so I know it's here and what it's for.
- Real sample data (even a small slice) dramatically improves the suggestions I can make.
- Strip anything truly sensitive before uploading if this is going to a shared/cloud context.
