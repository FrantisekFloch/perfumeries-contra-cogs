B2 — Recovery basket / cart

Every finding has an Add to claim action. A basket accumulates the selected lines with a live count and total. When ready, the user opens the basket, reviews the exact lines, unchecks anything to exclude, and hits one obvious Generate Contra-COGS. "Where do I generate it?" now has an always-visible answer.

Combines the "stage then commit" human-in-the-loop rule (workflowbuilder.io) with reconciliation "select then post" gating (Continia, Oracle ARCS). Rephrased for compliance.

B1 — Connect-the-dots canvas

A per-supplier canvas of invoices, delivery notes, goods receipts and events. Solid green edges = matched / qualifying; dashed red = broken / at-risk (missed scan, forgotten SKU, late vs window). Click any node to include or exclude it from the claim — the running total updates. Generate is only enabled once the selection is confirmed.

B3 — Consolidated per-supplier debit

Group the selected findings by supplier and merge their lines into one consolidated debit statement — tick the lines to include, untick to drop — with every source finding kept as a traceable sub-line. One clean statement per supplier instead of many little ones.

Your idea, expanded. Standard consolidated-document pattern: Odoo (merge → auto credit notes + batch tracking), Oracle ERP (consolidate charge lines), Octopus.

Overview

★ Recommended combined flow

Three pieces that reinforce each other, each mapping to a proven pattern.

1 · Live evidence pipeline on load A1

The user watches connect → match → reconstruct → count, ending on "15 recoverable found · €3,491" that is the button into the workspace. Builds trust and context before any ask.

2 · "Claim Builder" stage driven by a recovery basket B5 + B2

Findings get an "Add to claim" action; a sticky basket shows count + total; the Claim Builder stage is where you review the staged lines, exclude what shouldn't be claimed, and generate. Makes "where is it generated?" self-evident.

3 · Consolidate per supplier inside the builder B3

A toggle that turns several selected findings for one supplier into a single consolidated debit with selectable lines.

The connect-the-dots canvas (B1) is best slotted in as the "expand a supplier" drill-down inside the Claim Builder — the richest way to decide inclusion visually, without overwhelming users on first contact.

All mockups here are static concepts for review — no data or logic is wired to the real tool.
